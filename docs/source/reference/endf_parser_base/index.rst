endf_parser_base
================

The ``endf_parserpy.endf_parser_base`` module implements
only a single class :class:`EndfParserBase`, which
is also exposed in the global namespace of the
``endf_parserpy`` package. The warning issued by both
parsers for the mismatches they tolerate,
:class:`~endf_parserpy.EndfToleratedMismatchWarning`, is
also described here.
